# 01: Make Playwright MCP Bun-native

**What to build:** OpenCode users can load the project MCP configuration and start the official Playwright MCP server through Bun, with the existing project-local integration still usable.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] MCP launcher uses Bun rather than npm.
- [ ] OpenCode accepts the configuration.
- [ ] Playwright MCP starts or exposes help output through the configured launcher.
- [ ] No application behavior or unrelated configuration is changed.
